# ADYA — privacy policy

This repository exists only to host the privacy policy for the ADYA iOS/Android
app at a public URL, which the App Store and Play Console both require.

Published at <https://sarang-code2.github.io/adya-privacy/>

The canonical copy lives in the app repository as `PRIVACY.md`. When it changes
there, copy it here as `index.md` and update the "last updated" date in both.
